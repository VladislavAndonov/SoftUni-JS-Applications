# SoftUni - JS Applications Module Exercises

This repository contains solutions for exercises from the **JavaScript Applications** module at SoftUni. The exercises cover a range of topics including:

- **Asynchronous Programming**
- **Remote Data and Authentication**
- **Single Page Applications**
- **Architecture and Testing**
- **Client-Side Rendering**
- **Routing**

## Backend
For some of the applications, I am using the [SoftUni practice server](<https://github.com/softuni-practice-server/softuni-practice-server>), which is a REST service created specifically for educational purposes. The server provides backend functionality for various exercises in this repository.

## Running the Apps
Applications, such as the **Architecture and Testing/softTerest**, **Routing/furniture**, **Exam** and **Exam preparation**, can be started with the following command:

```bash
npm run start
```
This will start the app on **http://localhost:3000**.

## Testing
For unit and integration testing, I am using the following tools:

- **Mocha**: A test framework for Node.js
- **Chai**: An assertion library for Node.js

You can run the tests by executing:
```bash
npm test
```
